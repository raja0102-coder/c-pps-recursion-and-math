# PPS Recursion & Mathematical Algorithms Engine

A Semester 1 Programming for Problem Solving (PPS) C application exploring call-stack unwinding, base condition verification, divide-and-conquer strategies, and mathematical problem solving.

## PPS Concepts Covered
* **Call Stack Execution**: Visualizing active activation records during nested function calls.
* **Base Case Safeguards**: Eliminating infinite call loops and stack overflow exceptions.
* **Euclidean Algorithm**: Computing GCD using modular recursive reductions.
* **Tower of Hanoi**: Solving $O(2^n)$ combinatorial puzzles via structural recursion.

## How to Compile & Run
```bash
gcc main.c -o recursion_math
./recursion_math
